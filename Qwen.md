# Qwen Code context

Use the repo-wide agent guidance in [AGENTS.md](./AGENTS.md). It is the canonical source for project structure, commands, working rules, and verification.

Rapunzel is a React Native 0.72 app for reading and downloading books and manga from Lilith repositories. The app uses React Navigation, React Native Paper, Taihou for state and effects, MMKV for persistence, and a custom image cache.

The main implementation is in `src/`. Tests are in `__tests__/` and `scripts/__tests__/`. Native projects are in `android/` and `ios/`.
